## 0. Executive Architecture Summary

The portfolio is a high-performance, editorial publishing platform and personal workspace powered by **Eleventy (v2)**, **Node.js**, **KaTeX**, **Cloudflare R2**, and an **Obsidian-inspired private admin system**.

```text
                                GITHUB REPOSITORY
                           (Canonical Source of Truth)
                         Markdown + YAML + WebP Assets
                                       │
                                       │ Direct GitHub API Commits / Sync
                                       ▼
                         ┌───────────────────────────┐
                         │          VERCEL           │
                         │   Unified Production App  │
                         └───────────────────────────┘
                           │                       │
                           ▼                       ▼
                  PUBLIC PORTFOLIO           PRIVATE ADMIN & API
                  • Eleventy SSG             • Passcode & OAuth Auth
                  • KaTeX Math Rendering     • WYSIWYG & Raw MD Editors
                  • As-You-Type Search       • KaTeX Math Toolbar Engine
                  • RSS Feed & Sitemap       • Resume PDF Manager
                  • R2 Media & Plates        • Security Rate-Limiting
                           │                       │
                           └───────────┬───────────┘
                                       │
                                       ▼
                           Serverless REST API (/api/*)
                           Backed by Environment Variables
                           & Crypto Timing-Safe Security
```

### Core System Principles
1. **No Database Lock-in**: GitHub is the single, version-controlled source of truth. All content is persisted as clean Markdown (`.md`) with YAML frontmatter.
2. **Unified Vercel Hosting**: Public pages and `/admin/` API endpoints are served from a single Vercel production project (`https://abantika-xplore.vercel.app/`).
3. **Editorial Bauhaus Aesthetic**: Hairline borders (`#d4d1c9`), off-white paper (`#f2f0ea`), deep ink (`#111`), red accents (`#e03c31`), DM Mono, Inter, and numbered UI hierarchy.
4. **Defense-in-Depth Security**:
   - IP-based rate limiting (5 attempts / 15-minute ban).
   - Timing-safe cryptographic comparison (`crypto.timingSafeEqual`).
   - 450ms artificial response delay penalties for failed authentication.
   - HTTP-only HMAC-SHA256 signed session cookies.
   - Full Git version history allowing 1-click disaster recovery.
5. **Native LaTeX Mathematics**: Server-side static math compilation during Eleventy builds with client-side fallback rendering and interactive admin formula builder.

## 4. Disaster Recovery & Emergency Operational Playbook

### Scenario A: Forgot Secret Passcode
1. Log into [Vercel Dashboard](https://vercel.com/) $\rightarrow$ **Settings** $\rightarrow$ **Environment Variables**.
2. Update `ADMIN_PASSCODE` to a new secret.
3. Click **Redeploy**. Access is restored immediately.

### Scenario B: Suspected Unauthorized Admin Login
1. Change `SESSION_SECRET` in Vercel Environment Variables.
2. Click **Redeploy**. This invalidates all active session cookies globally, kicking out the intruder.
3. Change `ADMIN_PASSCODE` to lock down future access.

### Scenario C: Unwanted Content Deletion or Vandalism
Because all content is backed by Git:
1. Open your terminal in the workspace directory.
2. Run:
   ```bash
   git log -n 5
   git revert HEAD
   git push origin main
   ```
3. The site immediately restores to its clean state.
